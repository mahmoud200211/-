# تقييم المدربين والطلاب في المساجد

## محتويات المجلد
| الملف | وظيفته |
|---|---|
| `index.html` `style.css` `script.js` | الموقع نفسه |
| `logo.png` | شعار الأكاديمية (استبدله بشعارك بنفس الاسم) |
| `data/students.csv` | أسماء المدربين والمساجد والطلاب (مأخوذة من ملف الإكسل) |
| `apps-script/Code.gs` | كود يحفظ التقييمات في Google Sheet |
| `tools/build_data.py` | يحوّل ملف الإكسل إلى `students.csv` عند تحديث الأسماء |

## الخطوة 1: إنشاء الجدول (قاعدة البيانات)
1. ادخل إلى sheets.google.com وأنشئ جدولاً جديداً باسم "تقييمات المساجد".
2. من القائمة: **الإضافات (Extensions) ← Apps Script**.
3. احذف أي كود موجود، والصق محتوى `apps-script/Code.gs` كاملاً، ثم اضغط حفظ.
4. اضغط **Deploy ← New deployment**، واختر النوع **Web app**.
5. اضبط: *Execute as* = **Me**، و *Who has access* = **Anyone**.
6. اضغط Deploy ووافق على الصلاحيات (قد تظهر رسالة "Google hasn't verified": اضغط Advanced ثم Go to project).
7. انسخ **Web app URL** (ينتهي بـ `/exec`).

## الخطوة 2: ربط الموقع بالجدول
افتح `script.js` وعدّل أول سطرين في `CONFIG`:
```js
ACADEMY_NAME: 'جيكس أكاديمي',
APPS_SCRIPT_URL: 'الصق هنا رابط /exec',
```

## الخطوة 3: النشر على GitHub Pages
1. أنشئ مستودعاً (Repository) جديداً على GitHub، وارفع كل ملفات هذا المجلد.
2. **Settings ← Pages**، واختر Branch = `main` والمجلد `/ (root)` ثم Save.
3. بعد دقيقة يظهر رابط الموقع، وهو الذي ترسله للمدربين.

## تحديث الأسماء لاحقاً
`python3 tools/build_data.py ملف_الأسماء.xlsx data/students.csv` ثم ارفع `students.csv` الجديد.
(شكل الإكسل: ورقة لكل مسجد، أعمدة: الاسم، المسجد، المنطقة، المشرف.)

## شكل ملف الأسماء `data/students.csv`
| المدرب | المسجد | المنطقة | الطالب |
|---|---|---|---|
| محمد صالح الدخيل | مسجد الصحابة | قدسيا | عبد الهدي صالح |

- الطالب الذي له أكثر من مشرف يُكتب في صف لكل مشرف.
- جامع القدم الكبير لا يوجد له مشرف في الملف، فظهر باسم "مشرف غير محدد - جامع القدم الكبير". عدّل الاسم في العمود الأول عند معرفته.

## ملاحظات
- التقييم يُحفظ في ورقتي "تقييم الطلاب" و"تقييم المدربين". إعادة تقييم نفس الطالب أو المدرب تحدّث الصف نفسه ولا تكرره.
- إذا انقطع الإنترنت يُحفظ التقييم على الجهاز ويُرسل تلقائياً لاحقاً.
- الرابط عام: أي شخص يملكه يستطيع الدخول، فشاركه مع المدربين فقط.
