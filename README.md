# تقييم المدربين والطلاب في المساجد

## محتويات المجلد
| الملف | وظيفته |
|---|---|
| `index.html` `style.css` `script.js` | الموقع نفسه |
| `logo.png` | شعار الأكاديمية |
| `data/students.csv` | أسماء المساجد والطلاب والمشرفين (من ملف الإكسل) |
| `apps-script/Code.gs` | كود يحفظ البيانات في Google Sheet |
| `tools/build_data.py` | يحوّل ملف الإكسل إلى `students.csv` |

## طريقة عمل الموقع
1. الصفحة الأولى: في الأعلى زرّان "تقييم الطلاب" و"معلومات عن المدرب"، وتحتهما أزرار المساجد.
2. "تقييم الطلاب": اختيار المسجد ثم قائمة كل طلابه ثم نموذج التقييم.
3. "معلومات عن المدرب": اختيار المسجد ثم نموذج المعلومات.
4. الضغط على الشعار يعيد الموقع إلى الصفحة الأولى من البداية.
5. اسم المدرب يُختار من مشرفي المسجد، أو يكتبه بنفسه إذا لم يجده. الاختصاص والمهارات الأخرى فيها خانة يضيف فيها ما يريد.

## الجدول (Google Sheet)
تُنشأ تلقائياً ورقتان: **تقييم الطلاب** و**معلومات المدربين**. إعادة التقييم لنفس الطالب (أو نفس اسم المدرب) تحدّث الصف نفسه ولا تكرره.

### عند تعديل `Code.gs`
في Apps Script: **نشر ← إدارة عمليات النشر ← ✏️ ← إصدار جديد (New version) ← نشر**. بهذا يبقى الرابط نفسه.

## تحديث الأسماء
`python3 tools/build_data.py ملف_الأسماء.xlsx data/students.csv` ثم ارفع `students.csv`.

شكل الملف:
| المسجد | المنطقة | الطالب | المشرف |
|---|---|---|---|
| مسجد الإيمان | المعضمية | تيم ادريس | محمد رفاعي\|محمود الواوي |

- أكثر من مشرف للمسجد تُفصل بـ `|`.
- جامع القدم الكبير لا مشرف له في الملف، فيكتب المدرب اسمه بنفسه.

## النشر على GitHub Pages
**Settings ← Pages ← Deploy from a branch ← `main` و `/ (root)` ← Save.**
